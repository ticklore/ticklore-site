# Ticklore — Privacy & Discretion Defaults

**Positioning rule (non-negotiable):** Ticklore is **never marketed as a "recovery ticketing
platform."** Doing so would disclose by association — any organizer using it would be labelled, and a
branded keepsake could out an attendee simply by existing. These are **platform capabilities available
to any event**, spoken about as "discreet" or "privacy-first," and — where the room already knows why
it matters — described in a *pitch, verbally* as "recovery friendly." Never in public marketing, never
as a named segment.

Practically: Ticklore serves small-to-medium community events. Some of those are anonymity-sensitive.
The defaults below simply make the platform safe for all of them.

---

## The defaults

### 1. First name + last initial
- Keepsakes display **first name and last initial** — "Alex W.", never a full surname.
- This is the recovery community's own convention, and it's the right one: in a crowd of 150 there are
  four Mikes, so a first name alone is ambiguous — **insiders know exactly who it is, outsiders are
  left guessing.** Identifiable to the people who were there; useless to anyone who wasn't.
- Full surnames are **never rendered on the keepsake and never written on-chain.** If a surname is
  collected at all (e.g. for the organizer's own reconciliation), it stays off the permanent record.
- Reads warmer anyway — good for every event, not just sensitive ones.

### 2. No public roster — ever
- Attendance is **never listable**: not publicly, not by other attendees.
- No "who else is here" view unless an attendee explicitly opts in.
- No wallet-address-to-identity linkage exposed anywhere.

### 3. Neutral on-chain labelling
- The permanent, public record must **not** state the nature of a sensitive event.
- On-chain: a neutral event name or ID (e.g. "Serenity 2026"). The full framing, description, and
  context live in the **gated vault**, not the chain.
- Rationale: a first name permanently tied on a public ledger to an explicitly-labelled recovery event
  is a disclosure that can never be undone. The chain proves the keepsake exists; only the vault says
  what it was.

### 4. Gated vault
- Photographs and written memories are visible **only to holders of a keepsake from that event.**
- Never on the open web, never indexed, no public share links by default.
- Applies to write-ups as well as images.

### 5. Permanent non-transferability (per event)
- Organizer can mark an event's keepsakes **permanently non-transferable**, so a keepsake can never be
  sold or passed to someone outside the community. (Already in the contract.)
- Recommended default **on** for anonymity-sensitive events.

### 6. Attendee data belongs to the organizer — full stop
- **Ticklore never markets to an organizer's attendee list, never sells access to it, and never uses it
  to promote other events.** Put this in writing in the organizer agreement.
- This is the sharpest contrast with Eventbrite, which co-owns attendee data and markets competing
  events to it. For an ordinary event that's an annoyance; for an anonymity-sensitive one it means a
  list of attendees sits in a marketing database, gets used for targeting, and can be breached.

### 7. Photo contributions are gated and reviewed
- Attendee-submitted photos require approval before they enter the vault (organizer-controlled).
- Consistent with the existing rule that permanent records get a checkpoint **before** they're written,
  never after.

## How this is presented

| Context | Language |
|---|---|
| Public site / plan | "Privacy-first. Discreet event options. The attendee list is yours alone." |
| Verbal pitch, in-community | "It's recovery friendly — first name and last initial, nothing public, no roster." |
| Never | "The recovery ticketing platform." Any public segment branding. |

## Why this is also a general-market advantage
These defaults are not a niche accommodation. "Your attendee list is never marketed to" and "nothing is
public unless you choose it" are compelling to **any** organizer — a school booster club, a private
gala, a company retreat. Built for the most sensitive case, they raise the floor for everyone.

## Applies immediately
Both current pilots are anonymity-sensitive community events:
- **Serenity on the Shore campout** — October 9–11, 2026, First Landing State Park (17th annual).
- **New Year's Eve gala** — December 31, 2026.

These defaults are therefore **not a future feature** — they are required for pilot #1.
